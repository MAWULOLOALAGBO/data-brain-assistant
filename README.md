# 🧠 Data Brain Assistant

Assistant d'analyse de données universel piloté par IA.

## Déploiement
1. Fork ce repo
2. Connecte-toi sur [Streamlit Cloud](https://streamlit.io/cloud)
3. Déploie depuis GitHub
4. Ajoute ta clé API OpenAI dans l'interface

## Fonctionnalités
- Upload CSV/Excel/JSON
- Requêtes en langage naturel
- Analyse automatique (stats, viz, prédiction)
- Génération de code Python
